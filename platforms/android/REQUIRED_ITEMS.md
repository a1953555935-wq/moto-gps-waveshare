# Android 版所需物品清单

## 开发与首次连接

- [ ] 一台可运行 Android Studio 的 Windows、macOS 或 Linux 电脑，留出安装 Android SDK、JDK 和 Gradle 依赖的空间。
- [ ] 一部支持 BLE 的 Android 手机（Android 8.0 或更新），可开启蓝牙和精确定位。圆屏连接必须用真机验证。
- [ ] 一台**微雪 ESP32-S3-Touch-AMOLED-1.75C** 成品设备。购买时核对型号末尾的 `C`、32 MB Flash 和 8 MB PSRAM；不要仅凭“1.75 英寸圆屏”选购。
- [ ] 一条可传数据的 USB-C 线，用于识别、备份和烧录设备。
- [ ] 与仓库相匹配的 MOTO GPS 固件；烧录前先备份原厂固件。编译固件使用 ESP-IDF 5.5.5。
- [ ] 能下载 Android、Gradle、ESP-IDF 依赖的网络。

## 真实地点搜索和路线规划时再准备

- [ ] 自己的高德 Web 服务 Key，配置在本仓库 `backend` 网关的服务器环境中。
- [ ] 手机可访问的 HTTPS 网关地址。Key 不写进 APK。

## 户外使用时再准备

- [ ] 与该成品设备接口、极性和尺寸相符的电池或可靠供电方式。
- [ ] 适配实际外壳的车把固定件，并检查防水、防震与供电。

首次桌面联调只需电脑、Android 真机、准确型号的圆屏和数据线；电池、车把固定件及高德 Key 可以后备。当前 App 仍处开发阶段，没有可验收的导航安装包。
